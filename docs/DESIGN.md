# Rainpans 設計書

雨を受けて音にする、アンビエント・インクリメンタル。
「急がない」「失敗しない」「数字は控えめに」を守り、雨音と灯りを主役にする。

## 1. 体験の芯

- 雨は勝手に降る。プレイヤーは**どこに何を置くか**だけを考える。
- 置いた位置が音程になる（左→右でペンタトニックを上がる）。どう並べても濁らない。
- 響き（通貨）は「たくさん聴いた証」。強化は雨そのものを豊かにする方向にだけ働く。
- 自分で叩くこともできる（クリック／キーボード／ホイールで音程）。ただし主役は雨（手で叩くと響きは 0.6 倍）。
- 手で弾いたフレーズは R で録音してループできる（72 BPM の拍に丸め、最大 32 拍、場所ごとに保存）。

## 2. ゲームの流れ

```
雨粒（深さ付き）が落ちる ──▶ 同じ深さに立つ雨受けの口に当たる ──▶ 音＋響き
     ▲                                                          │
     └──── 雨脚・雨樋・残響・灯り・こだま / 新しい雨受け / 新しい場所 ◀──┘
```

### 当たり判定（2.5D）
雨粒はそれぞれ「落ちる床の深さ（y）」を持つ。雨受けは自分の足元の y の前後 −9〜+3px に
落ちる粒だけを、口（`lid` の x 範囲）の高さで受ける。これで奥と手前が自然に分かれる。
ひさしの下（`shelters`）には雨は届かず、縁の `drips` から一定間隔でしずくが落ちる
（＝リズムを刻む場所）。

### 場所

| 場所 | 解放 | 倍率 | 置ける数 | 特徴 |
| --- | --- | --- | --- | --- |
| 崩れた屋上 | 最初 | ×1 | 20 | トタンのひさし、ランタン、給水塔、カラス |
| 途切れた高架 | 5,000万 | ×3 | 24 | 駅のひさし、窓の灯る廃電車、沈んだ街、風の音 |
| 割れた温室 | 15億 | ×5 | 26 | 鉄骨のガラス屋根、割れた窓からだけ雨、伝う雨筋、噴水と植物 |
| 地下水路 | 800億 | ×12 | 28 | 天井の穴からだけ雨、光の柱、水の音、長い残響 |

雨受けの「持ち数」は共通で、場所ごとに別々に並べられる。

### 強化

| 名前 | 効果 | 値段 |
| --- | --- | --- |
| 雨脚 | 雨粒 ×1.12、響き ×1.2 / Lv（最大10） | 50 × 4.5^Lv |
| 雨樋 | しずくの落ちる場所が増える（最大6） | 300 × 5^Lv |
| 残響 | 響き +20% / Lv、残響が深くなる（最大5） | 2,000 × 6^Lv |
| 灯り | 響き +25% / Lv、光が広がる（最大3） | 5万 × 12^Lv |
| こだま | 響き ×1.5、ディレイが入る | 100万 |
| 夜をすすめる | 時間が流れる（夕暮れ→夜→夜明け→朝） | 300万 |
| 雨上がりを待つ | エンディング（地下水路で解放） | 5兆 |

さらに「置いた雨受けの種類の数 −1」×10% のハーモニー倍率。

### 雨受け（11種）
値段は段ごとに約 12 倍、1 回あたりの響きは約 3 倍。2 個目以降は 1.7〜2.0 倍ずつ値上がり。
詳しい数値は `src/data/drum_defs.gd`。バランスは `tools/balance_sim.py` で確認する
（最適に近い遊び方で全体が約 5.5 時間、実際の遊び方では 8〜10 時間の見込み）。

### 放置
留守のあいだは、直近の毎秒の響き × 50% を最大 8 時間ぶん受け取る。

## 3. 音

- **サンプルは一切使わない**。起動時にモーダル合成（減衰する正弦波の重ね合わせ）で
  雨受けごとの音を作る。素材の違いは倍音比と減衰時間で表す。
- 音程は D メジャー・ペンタトニック。位置で決まり、ホイールで ±5 段ずらせる。
- バス構成：`Drums`（リバーブ→ディレイ（こだま）→ローパス）、`Ambience`（ローパス）、
  `Master`（コンプレッサー）。
- 雨音の環境音は、ピンクノイズの「さー」と細かい粒の「ぱらぱら」の 2 層。
  場所ごとに水の流れ／風の音を足す。
- 強い雨で音が飽和しないよう、雨の音は毎秒約 11 音まで（超えた分も響きは入る）。
- 「拍にそろえる」をオンにすると、72 BPM の 8 分音符に寄せる。

## 4. 絵

- 解像度 320×180、整数倍拡大。画像ファイルは使わず、すべてコードで描く
  （`PixCanvas` に点・線・多角形・ディザのグラデーション）。
- パレットは約 40 色に固定（`Pal`）：雨の青、コンクリート、錆、苔、灯りの琥珀色。
- 光（OneShot を意識）
  - ランタンは帯状にディザをかけた PointLight2D、加算合成の光輪、炎のゆらぎ
  - 雨受けはランタンに向いた縁だけが暖色に光り、反対側に長い影が伸びる
  - 濡れた床にランタンが揺れて映る。雨粒も灯りの近くでは暖色になる
- 粒子と環境：雨 2 層、しぶき、水たまりの波紋、しずく、霧の帯、煙と湯気、
  雨水の筋、航空障害灯、風に揺れる草、蛾、カラス、稲光と雷。
- 時間：夕暮れ・夜・深夜・夜明け・灰色の朝。地平線の光と全体の色味が変わる。
- 色の段階は slynyrd 式に色相をずらす（影は青紫寄りで彩度高め、明部は暖色寄りで彩度低め）。
- 置いた雨受けは景色になじませる：輪郭線はベタ黒を底と影側だけに残し、他は接する色の暗部に。
  奥ほど夜気に霞み、底は濡れた床に沈み、床には崩れた映り込みが落ちる。

## 4.5 出来事（人は出てこない）

- 来訪者：数分おきに一体だけ、静かに来て、去る。
  - 猫（屋上・線路・温室）：雨受けの横に座り、ときどき前足で鳴らす
  - 古い整備ロボット（全域）：ライトを点けて巡回し、雨受けを二度ずつ叩いて点検する
  - 鷺（運河）：水辺で立ち止まり、ときどき水面をつつく
  - 鹿（温室）：迷いこんで草を食む
- 落雷：嵐や強い雨のとき、数分に一度ほど近くに雷が落ちる。稲妻、白い閃光、
  すぐ鳴る雷鳴。置いてある雨受けがいっせいに鳴り、響きが少し入る。

## 5. 文と世界

- 「雨の手帳」：節目ごとに一行だけ浮かぶ短い文（24 文）。設定画面から読み返せる。
- 世界観は『少女終末旅行』の「雨音」の空気（廃墟で雨宿りしながら、いろいろな物に
  落ちる雨の音に耳を澄ます）を参考にしつつ、人物・場面はオリジナル。
- エンディング「雨上がり」：雨が弱まり、やみ、夜明けが来て、静かなタイトル。
  しばらくすると、また雨の音がして遊びは続く。

## 6. 作り方と確認

| コマンド | 内容 |
| --- | --- |
| `tools/setup_godot.sh` | Godot 4.3 を入れる（クラウドでは SessionStart フックで自動） |
| `tools/ci.sh` | 構文チェック → ロジックテスト → 入力シナリオ（配置・演奏・移動・ループ） |
| `tools/shot.sh out.png --demo` | 仮想ディスプレイでスクリーンショット |
| `tools/scenario.sh sheet` | 雨受けのドット絵一覧（`shots/sheet.png`） |
| `--write-movie` + `tools/spectrogram.py` | 音を WAV に書き出し、スペクトログラムで確認 |
| `tools/export.sh` | Web 版・Windows 版を書き出す |

デバッグ用の起動オプション：`--demo` `--area=rail` `--phase=0.8` `--rain=10` `--full`
`--ending` `--speed=8` `--shelf` `--upgrades` `--settings` `--crow` `--reset`。
