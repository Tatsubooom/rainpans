Rainpans — 雨受けの音を集める、静かな放置ゲーム

■ 遊び方
  Rainpans.exe をダブルクリックするだけで始まります（インストール不要）。
  Windows に「PC を保護しました」と出たら「詳細情報」→「実行」を押してください
  （署名をしていない個人制作の exe のため表示されます）。

■ 操作
  ・「棚」から雨受けをドラッグして床に置く。雨が当たると鳴って「響き」がたまる
  ・置いた雨受けはクリックで鳴らせる／ホイールで音の高さを変える
  ・数字キー・キーボードの段で演奏、R で録音とループ
  ・「手入れ」で雨脚や灯りを強くする。新しい場所へも行ける
  ・P で写真モード（UI を隠す）、Esc／… で設定
  ・棚にしまってある雨受けも、少しだけ（1%）響きを集める
  ・閉じても進行は自動で保存され、留守のあいだも少し響きがたまる

■ セーブの場所
  %APPDATA%\Godot\app_userdata\Rainpans\
